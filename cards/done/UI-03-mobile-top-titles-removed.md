# UI-03 手机端删掉照片页/设置页的顶部大标题　级别 L3

> ✅ 状态：代码已合并，2026-08-27 真机验收通过，验收人认定归档
> 级别：L3 · 阻塞：无

## 问题

手机端照片页顶部有 30sp serif 大标题「全家的照片」、设置页有 28sp serif
大标题「设置」。底部 tab 已经写着「照片」「设置」——大标题是**同一句话说
第二遍**，而且吃掉手机上最金贵的首屏纵向空间（照片墙的第一行、英雄卡的
三元组都被往下推了约 68dp / 42dp）。

2026-08-21 真机用户裁决（原话）：

> 「mobile 端照片和设置页面，顶部有必要有几个大字吗？【全家的照片】【设置】，
> 是否可以删除了，占位置还没有什么意义。」

## 期望行为

照片页/设置页顶部无大字标题：照片页第一行照片、设置页英雄卡上移，不贴
状态栏（状态栏安全区由 `PPScreen` 的 `safeDrawingPadding()` 负责，与标题
无关）。

## 实施记录

改动：

| 文件 | 原来 |
|---|---|
| `PhotosScreen.kt` | `photos_title`「全家的照片」30sp serif，`padding(24,18,24,10)` → 换成 `Spacer(8.dp)` |
| `HomeScreen.kt` | `tab_settings`「设置」28sp serif + `Spacer(14.dp)` → 整块删除（Column 自带 14dp 顶部内边距，英雄卡不会贴边） |

`photos_title` 这个 string 资源**保留**（en/zh 对称），只是不再渲染——桌面端
和将来可能的顶栏还用得上，删了会让 i18n 对称测试和翻译文件白掉一条。

状态栏安全区由 `PPScreen` 的 `safeDrawingPadding()` 负责，与标题无关，删标题
不会顶到状态栏。

为什么这个偏离是对的：底部 tab 已经写着「照片」「设置」；桌面端不同——
那边窗口大、标题承担导航功能。手机上这个功能已经由 tab 承担了。
