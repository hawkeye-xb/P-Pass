## 内容覆盖

**桌面端（管理员）**
- 侧边栏五页：总览 / 照片 / 家人与设备 / 活动记录 / 设置
- 断点：≥1440 三栏 + 摘要卡 · 1080–1439 两栏 · <1080 图标轨 + 单栏
- 总览：服务状态徽章、照片总数/最近备份、待确认配对横幅（拒绝/允许加入）、
  备份水位、添加设备（二维码弹窗 + 复制配对串）、最近动静摘要 + 全部活动记录链接
- 照片：Finder 入口、按月分组、缩略图只用于翻找的说明
- 家人与设备：行内「移除」、经中继提示
- 活动记录：「本周」统计（新备份/去重跳过/重试成功）、90 天保留说明
- 设置：照片库位置、磁盘空间、开机自启、版本/检查更新、电脑名字、
  导出诊断包（自动抹隐私路径）、停止后台服务
- 新增：桌面首启向导（存哪 / 保持醒着 / 常驻服务 / 配对码）、配对二维码放大弹窗

**Android 端（家人）**
- 欢迎/扫码连接、时间线（↑待备份 ↓仅在电脑 标注）、备份页（进度/规则/白名单建议）、
  失联页（重新扫码连接）、Onboarding（权限三步 / 相册选择 / 备份时机）、大图页
  （保存到手机 / 分享）
