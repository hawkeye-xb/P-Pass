## 回归工具的改进（随 #869 合入）

- `tools/ipc-lib.sh`：Windows 命名管道；管道忙（errno 22）时重试——并发 8 路 120 次全部成功。

- `tools/windows/uia-drive.ps1`：用 UI Automation 点桌面窗口，向导与设置页不再需要人。

## 发版结论

Windows 当前**不具备正式发布条件**：#871 让每一个新用户首启失败，必须先修；#877 影响重装用户的开机自启，建议一并修。签名（#845 / #846）仍按验收人决定暂缓。数据路径本身（备份、升级、断网、崩溃恢复、断开与重配、隐私）在 Windows 上全部通过。
