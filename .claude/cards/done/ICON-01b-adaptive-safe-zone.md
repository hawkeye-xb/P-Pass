# ICON-01b Android 图标被放大裁切　级别 L1

## 现象（三星真机 2026-08-12）

launcher 图标像被放大，脸展示不全。根因几乎必然是：自适应图标前景层
PNG 用了全幅构图（脸占画布 ~77%），而系统遮罩只显示中心 ~66% 安全区
→ 视觉=放大裁切。ICON-01 卡面写了「66% 安全区缩排」，复查
scripts/icons/generate.sh 的前景生成步骤是否真做了缩排。

## 修法

前景层按 108dp 网格出图：兽面内容整体缩放到中心 66dp 安全圆内
（相对全幅约 0.61 缩放，留白是遮罩的呼吸区）；背景层纯色 paper 不变；
monochrome 层同样复查。

## 可执行验收

1. 模拟器圆形/方形/圆角三种遮罩截图：脸完整、双角双眼嘴全部在遮罩内。
2. 与 iOS 风格方图标（桌面端）并排对比大小观感协调（贴图）。
3. 反证：撤掉缩排 → 圆遮罩必裁角（贴对照后还原）。
