## 意见分三级（#1470）

每条意见必须以级别开头，三选一：

- `[阻断]`：只有这三类——**误放行**（门禁、判定、检查会把该挡的放过去，或把没过的报成全清：声称「已修复」却拿不出「故障在场时红 → 修复后绿 → 撤销回红」的原始输出，或复现不了却写成「已修复」，都算把没过的报成全清）、**安全**（凭据、权限、注入、隐私外泄）、**越界**（改了卡「范围」外的路径，或卡上验收场景明确要求的事没做 / 没有能判红的测试）。
- `[建议]`：值得改、但不改也不会误放行、不涉安全、不越界的（同类遗漏的次要位置、可读性明显差、测试可以更全等）。
- `[风格]`：措辞、命名、注释、格式。尽量少提。

拿不准是不是阻断的，按建议写。建议和风格不挡合入，由开 PR 的会话自己判断改不改。
