在 iPhone 上用外部相机或专业录制应用拍高码率视频时，素材通常会保存在「文件」应用的「我的 iPhone」独立文件夹里。从 P-Pass 0.12.1 开始，你可以在不授予系统相册权限的情况下，直接授权这个独立文件夹，把里面的照片和视频原文件自动传回家里 Mac 或 Windows 电脑的普通文件夹。

过去这类文件往往卡在两难里：导出进系统相册，同一段 4K 视频会在手机上立刻占两份空间并混进日常照片；留在应用自己的本地文件夹里，常规相册备份又扫不到它，插线手动拷贝大目录还容易在电脑端多出一次整理步骤。P-Pass 解决的就是把「我的 iPhone」下的指定目录直接放进自动备份列表，原片落盘，不经云端。

## 只备份独立文件夹时，要交出整个相册权限吗

不需要。P-Pass 把系统相册和本地文件夹拆成两条互不干扰的来源。

在手机端进入「Settings -> Backup range -> Add a Folder」，用系统目录选择器挑中目标文件夹之后，只要你不额外勾选任何系统相册，开启自动备份时 App 就不会向你索要系统相册读取权限。授权列表里会直接显示真实文件夹名称（例如 `Media`），方便区分来自不同录制工具的目录。

## 具体操作步骤（Mac / Windows 电脑配 iPhone）

整个配置分成四步，配好之后新拍进该文件夹的视频会在连上家里电脑时自动续传：

1. **准备电脑端存放目录**：在 Apple 芯片 Mac 或 64 位 Windows 电脑上打开 P-Pass，选一个用来存原始照片和视频的普通文件夹（放在本机硬盘或外接移动硬盘都可以）。如果 Windows 安装包首次启动弹出 SmartScreen 提示，点击「更多信息」，再点「仍要运行」。
2. **手机扫码配对**：在 iPhone 上安装 P-Pass（可通过官网首页的 App Store 或 TestFlight 公开入口获取），打开后扫描电脑端二维码，并在电脑上输入屏幕显示的 6 位验证码完成绑定。
3. **只授权目标文件夹**：进入「Settings -> Backup range -> Add a Folder」，在系统目录选择器里打开「我的 iPhone」，选中具体目录（例如 `Blackmagic Camera > Media`）并确认授权，该文件夹下的全部子目录会一并纳入范围。
4. **按需要设置起始日期**：如果只想备份从某一天之后新拍的素材，可以在同一页选定起始日期。P-Pass 会优先按照片 EXIF 或视频容器里的拍摄时间判断，读不到时再看文件修改时间，不会把目录挪动时间误判成拍摄时间。
5. **在电脑文件夹核对原文件**：传输完成后，电脑端照片页面会出现缩略图，同时在第一步选定的电脑普通文件夹里可以直接双击打开原视频文件，不经过转码或压缩。

如果你只是偶尔想把某几段视频发回电脑，不想开启整个文件夹的自动备份，也可以直接在首页使用「Choose from Files」，在系统文件选择器里一次多选几条视频单次发出。

## 备份过程会在手机上多占一份临时空间吗

不会长期多占一份空间。读取独立文件夹里的视频时，P-Pass 不先把整段数 GB 的文件复制到 App 自己的临时缓存目录，而是通过系统协调读取接口配合路径引用做流式分块哈希与传输，传完即止。

权限持久化方面，iOS 会把你在目录选择器里授予的访问权保存为安全作用域书签，重启 App 后自动恢复，书签快过期时也会在已有授权范围内自动刷新。如果后续文件夹被系统收回授权或路径暂时找不到，传输队列会暂停并明确提示需要重新授权，不会误判成照片被删。同一段视频即便之前已经通过系统相册传过一次，电脑端也会按全文件内容哈希判重，硬盘里只保留一份原文件。

## 哪些情况目前不支持

把本地文件夹加进自动备份前，先核对以下四条已明确的产品边界：

- **只支持「我的 iPhone」本机目录**：当前只覆盖 iPhone 本机存储中的文件夹及其子目录，不支持外接 USB-C 移动硬盘、云盘占位目录或第三方 File Provider 挂载目录。
- **只抓取照片和视频**：扫描时按系统文件类型识别照片和视频，同一文件夹里的工程配置、LUT、音频或文档会被直接忽略。P-Pass 只做照片和视频备份，不做全格式文件同步。
- **受 iOS 前台与后台窗口限制**：几 GB 的高码率视频建议保持 P-Pass 停留在前台传完；切到后台后传输能持续多久由 iOS 系统决定，中断后下次打开 App 会从断点继续。
- **单向只增不删，且电脑须保持唤醒**：备份只会往电脑文件夹新增文件，不会自动删掉手机里的原视频，也不会在电脑端复刻手机原有的子目录树。电脑关机或休眠时传输暂停，建议重要素材在电脑上另存一份到外接硬盘。
