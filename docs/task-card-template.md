# 任务卡模板 / Task card template

> 外派卡照此填。字段规则见 [AGENT_PROTOCOL.md §C](AGENT_PROTOCOL.md#c-任务分级与可验证验收)。
> 缺字段 = 不受理。定级不准往高一级放。

```
## 卡号 T-XXX  级别 L{0-3}

**目标**：一句话——做完什么算完成。

**范围**：只准动这些文件/目录。

**不准动**：相邻但不属本卡的东西（尤其未合并兄弟卡碰的文件）。

**可执行验收**：
  - 跑 `<命令>` → 期望 `<可复现的具体输出>`
  - [L1+ 故障/安全类必带] 反证：跑 `<去掉故障条件的变体>` → 必须变红

**证据要求**：报绿附命令 + 输出摘要。CI 绿不是唯一证据；声称"X 绿"贴 X 真实输出。

**跨卡声明禁令**：不许写"兄弟卡 Y 已落地"。Y 未合并只能写"待 Y 合并后成真"或列为前置。

**收尾**：just 全绿 + 更新 ROADMAP 对应行 + PROGRESS.md 一行。走 PR，完成后停下等 review。
```

## 级别速查

| 级别 | 类型 | 派给 | 验收 |
|---|---|---|---|
| L0 | 文案/删重复/同步/重命名 | 最低成本 agent | CI 绿 |
| L1 | 单文件 bug/判据/配置 | 中等 agent | 测试红→绿 + 反证 |
| L2 | 新协议/校验/架构 | 强 agent | 对抗 review + 真机/真数据 |
| L3 | VPS/真机/构建发布 | 运维/平台 agent/人 | 实证输出（日志/截图/健康检查）|
