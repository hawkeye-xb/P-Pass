# MOB-03 相册选择页全空白（权限链断了）　级别 L1　【加急第一：备份主流程死了】

## 根因（验收人已定位）

MOB-02 删掉首页手动备份按钮时，把原来挂在它身上的媒体权限申请链
一起删没了：`MainActivity:377 onOpenBucketPicker` 直接进 Screen.Buckets，
不检查/不申请 READ_MEDIA_IMAGES/VIDEO；`MediaScanner.listBuckets()`
无权限时 MediaStore query 静默返回空 → 用户看到全白，无从备份
（三星真机实锤 2026-08-12）。

## 修法

进入相册选择页前走完整权限链：
- 未授权 → 发起系统权限请求 → 完整授权后进列表；
- 部分授权 → MOB-02 §二 的引导态（「只授权了部分照片…」+去设置）；
- 拒绝 → 人话引导（不崩不白屏，说清为什么需要）。
onboarding 的「配对成功→选相册」入口同样过这条链。

## 可执行验收

1. 模拟器全新安装（零权限）→ 点「选择备份的相册」→ 系统弹窗出现 →
   允许后相册列表非空（贴截图）。
2. 拒绝 → 引导态显示，不白屏（贴截图）。
3. adb revoke 权限后再进 → 重新弹权限而不是白屏（反证：去掉权限检查
   → 此步必回到全白，贴对照后还原）。
4. android 全量绿。真机复核挂验收人。
