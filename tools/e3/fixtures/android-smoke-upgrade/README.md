# android/smoke-upgrade 判定回放（#1412）

每个反例只让一条判据出错（`fail` 除外），删掉或放宽那条判据，`tools/test-e3.sh` 的回放就会红。

- `pass/`：备份范围只有专用测试相册，桩里 8 张都是场景推的（6 + 升级后 2），手机账本也是 8。
- `fail/`：2026-11-05 #1444 的现象。范围里多了相机相册，当天拍的 3 张被一并备份，桩与账本都是 11、期望 8。
- `fail-scope/`：只有范围错（勾了相机相册，但相机相册当天恰好没照片），计数与素材都对。
- `fail-swap/`：范围与计数都对，但推的一张没进桩，被相册里另一张照片顶替。

数值是构造的（bucket_id 取三星上相机相册的真实值与一个示例值），rel_path 的格式取自真机证据，只用于离线回放判定。
