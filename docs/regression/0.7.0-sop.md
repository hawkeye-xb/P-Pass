- [ ] 设备：**Mate60（鸿蒙）+ 三星**（#572/#584 复现机优先）；桌面端 Mac/Windows 各一
- [ ] 从 draft release v0.7.0 下载 APK / dmg / exe

- [ ] 诊断包可导出

## 2. #584 专项验收（E3，两台复现机各做一遍）

### 2.1 Rust 日志可见性

```bash
adb shell logcat -v time -s PPassRust:* PPassFlow:*
```

- [ ] 传输一轮照片，logcat 里 **`PPassRust` tag 有 iroh 活动日志**（relay / net report 等）
- [ ] **隐私红线**：WARN 及以下不得出现本机公网地址（`iroh::net_report` 已压到 ERROR，肉眼抽查）
- [ ] 可选：`adb shell setprop log.tag.PPassRust DEBUG` 后 DEBUG 可见（鸿蒙同试；部分量产 ROM 无权限属预期，INFO 默认可见即可）

### 2.2 park 后 UDP socket 释放（#584 验收标准②）

```bash
# 取 App uid
adb shell dumpsys package com.hawkeyexb.ppass | grep userId=
# 连跑 3 轮传输，每轮后等 park 沉降（≥1 分钟，retire 上限 15s），然后查残留
adb shell cat /proc/net/udp /proc/net/udp6 | grep " <uid> "
```

- [ ] **连跑 3 轮传输 + park 之后，该 uid 在 `/proc/net/udp{,6}` 零残留**（修复前每轮泄漏一对 v4+v6）
- [ ] 若仍有残留：logcat 找 `PPassRust` 的 WARN（`Router::shutdown` 10s 超时 / drop 时 strong_count 告警会指认残留持有者），连同日志回传

### 2.3 流量对账（#584 验收标准①）

```bash
adb shell cat /proc/net/xt_qtaguid/stats | grep " <uid> "
```

- [ ] park 后静置 10 分钟，该 uid 流量增量 **≈0**；期间每一笔流量都能在 logcat（Kotlin 或 Rust 行）里对上原因

### 2.4 待机耗电对比（soak，建议过夜）

- [ ] 两台机器同电量充满、同网络环境，0.7.0 静置一晚（8h）记录掉电百分比；与 0.6.2-test.x 的既有记录对比，应明显回落
