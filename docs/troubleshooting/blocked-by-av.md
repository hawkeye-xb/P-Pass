# 被拦截了怎么办 — blocked by AV / SmartScreen

> 定位：Windows 上安装 P-Pass 时被 Defender / SmartScreen / 杀软拦下的处理指引。
> 截图占位：`[截图: 位置]` 标记处由人类（H 任务）补图——本文件是文档骨架，不是成品。

## 官方态度（先读这一段）

P-Pass 是开源软件：源码在 GitHub，构建可复现，每个发布产物都带
**SHA-256 + SLSA attestation**（下载页链接）。被杀软拦下 ≠ 软件有问题，
而是**新签名没有信誉**——所有新软件都会经历这个阶段。

验证三步走（不用信任何人的话）：

1. **对照 SHA-256**：下载页给出的哈希，与本地文件算出的哈希一致
   （`certutil -hashfile P-Pass-Setup-x64.exe SHA256`，macOS/Linux 用 `shasum -a 256`）。
2. **查 attestation**：GitHub Release 的 provenance 证明这个文件确实由
   P-Pass 官方 CI 构建，不是别人改过的。
3. **源码可查**：整个项目开源，构建流程在 `.github/workflows/` 里，
   不信任大可以自己编译。

> 如果你在我们的软件里真的发现了问题，欢迎提 issue——我们认真对待每一个报告。

## 场景一：SmartScreen 蓝屏提示"Windows 已保护你的电脑"

[截图: SmartScreen 蓝屏提示]

- **发生了什么**：新软件的签名信誉还没建立（发布初期常见，SmartScreen 对
  所有新发行商都这样，哪怕签名有效）。
- **怎么办**：点「更多信息」→「仍要运行」。
- **为什么安全**：见上方"官方态度"三步验证——验证通过即可放心运行。

## 场景二：Windows Defender 直接删除/隔离

[截图: Defender 隔离通知]

- **发生了什么**：Defender 的云查杀对无信誉文件会先隔离。通常 24~72 小时
  内随着更多用户安装，信誉建立后自动消失。
- **怎么办**：
  1. Windows 安全中心 → 保护历史记录 → 找到 P-Pass → 「还原」。
  2. 还原后如果再次被隔离，把文件加入排除项：
     Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加文件夹。
  3. 长期方案：向 Microsoft 提交误报申诉（提交后 1~2 个工作日处理）。
- **请帮我们一个忙**：如果确认是误报，把 Defender 的「检测名称」和
  诊断包（P-Pass 设置里「导出诊断包」）发给我们，我们统一提交申诉。

## 场景三：第三方杀软（360 / 火绒 / 卡巴斯基 / …）

[截图: 第三方杀软拦截弹窗（占位，品牌各不同）]

- **发生了什么**：各家杀软有自己的信誉库，行为与 Defender 类似。
- **怎么办**：在弹窗里选择「信任 / 添加到白名单 / 允许」，或在杀软设置里
  把 P-Pass 的安装目录加入白名单。
- **如果反复被拦**：把杀软名称 + 检测名称发给我们（issue 或诊断包），
  我们会去对应厂商提交误报申诉。

## 常见问题

**Q：提示"发布者未知"？**
A：说明可执行文件的签名信息还没被系统识别（发布早期）。验证 SHA-256
一致后即可信任；正式签名证书落地（H-02 凭据）后此提示消失。

**Q：我该卸载吗？**
A：先做"官方态度"里的三步验证。验证通过就不用；验证对不上（哈希不一致），
立刻卸载并告诉我们——那说明你拿到的文件不是我们发布的。

**Q：为什么不在发布前就把这些搞定？**
A：信誉是时间积累的，没有任何新软件能跳过。我们能做的是把"验证"这件事
做到最透明——这正是这个页面存在的意义。
