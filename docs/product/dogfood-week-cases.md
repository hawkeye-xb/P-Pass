## C 组 · 网络路径

- C1 同 WiFi 直连基线（全自动）
- C2 蜂窝→家 v6 直连体感速度（需人，鸿蒙）
- C3 强制 relay：可用 + 速度受限 + 路径展示如实（半自动）
- C4 空闲 30min NAT 保活后再传（★夜间，全自动，顺清挂账）

## D 组 · 数据完整性对账（gate 证据链，全部 agent 全自动）

- D1 **每晚对账**：范围内 MediaStore 数 vs daemon 该设备资产数 →
  完成率日报（gate 读数本体）
- D2 随机抽 N 张原图 hash 字节校验
- D3 随机取回老照片、字节一致
- D4 同内容经微信转存回流 → 去重不重传
- D5 奇葩文件全家桶（GIF/录屏/超长视频/无 EXIF）不炸且归位

## E 组 · 多设备并发（case 即并行）

E1 双手机同时备份；E2 一台备份中另一台浏览+取回；E3 备份中配对第三台。

## 并行规则与夜间编排

**冲突规则一条：B 组独占时段；移动端 case 按设备隔离天然并行。**

三晚示例（前半夜注入 → 凌晨自然触发 → 清晨 6 点 agent 对账日报）：

| 晚 | 编排 |
|---|---|
| 1 | 鸿蒙 A2-不加白 × 三星 A2-加白（对照）+ A4 + C4 → 晨 D1/D2 |
| 2 | 前半夜 B1 独占 → 后半夜 A1 + A3 恢复验证 → 晨 D1 |
| 3 | A9（adb 灌 500 张）+ E1 双机并发 → B7 启动（跨日验证节流） |

白天零头（需人）：A5-A8、C2、C3、B4/B5 体感走查。
三晚注入 + 四天自然运行 ≈ 原「一周等事件」全覆盖，D1 每晚产出 gate 证据。
