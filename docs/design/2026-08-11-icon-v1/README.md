# P-Pass Icon v1 — 屋脊兽 · Roof Guardian

> App icon design, finalized 2026-08-11. Primary icon: **carbon-stripe variant**
> (`icon-carbon.svg`). Design language and colors follow
> `assets/design/tokens.json` — warm paper, ink, and the ONE green that means safe.
> 中文为主档，本段为英文摘要。

## 设计理念（定稿叙事）

图标是**两个 P 面对面组成的一张屋脊兽脸**，每一笔都有出处：

1. **P-P 是颜文字**——产品名自带一张脸：两个 P 的圆弧是**眼睛**，
   机灵得像猫眼；瞳孔用调色板里唯一的**安全绿**（`safe #2E6B4F`，
   产品中它只表示「已存好」）——猫眼是绿的，说的就是「都存好了」。
2. **面对面**——右边的 P 镜像翻转，竖线到外侧、圆弧朝内：
   **手机和电脑，两端相对**。这也一次性解决了正写 P-P 的先天不对称
   （竖线都在圆弧左边，怎么摆重心都歪）。
3. **屋脊兽**——外侧竖线顶端向外一挑就是**双角**，底部圆角连线是
   **飞檐/嘴**：一笔勾出「角—脸颊—嘴」。脊兽守宅辟邪，P-Pass 守
   家里的照片——图标故事和产品说的是同一件事。
4. **左实右虚**——左半实墨 = 家里的电脑（实实在在存着）；右半
   碳纤维斜纹（或浅墨）= 在外面的手机。
5. **中心闪电**——嘴巴正中的折线闪电是**连接与传输**。它的中段
   斜线恰好穿过画布几何中心 **(512, 768)**，颜色在这个点上分界：
   连接的能量不属于哪一侧，它就发生在两端正中间——P2P 的语义由
   几何本身说出。

## 三个保留版本与分工

| 文件 | 版本 | 用途 |
|---|---|---|
| `icon-carbon.svg` / `-night` | **碳纹版（主图标，用户钦定）** | App 图标主档（macOS/Android/Windows）、启动页、README 头图 |
| `icon-tonal.svg` / `-night` | 色阶版（右半 ink-40） | 备选；斜纹不宜的中小尺寸场景可用 |
| `icon-beast.svg` / `-night` | 屋脊兽全实线版 | **≤40px 退化基准**：托盘、favicon、通知小图标——斜纹在小尺寸会糊成半灰，最小档换全实线，同一张脸近看有故事、远看依然清楚 |

`-night` 后缀 = 夜巡配色（`surface-dark #211E1A` 底、纸白线、
`safe-bg #E4F1E8` 瞳），深色桌面与托盘用。

## 几何规格（1024×1024 画布，全部脚本验证）

- 笔画宽 **72**，圆头端帽/圆角折点（闪电分色处用平头端帽对接）
- 眼环：r=146，圆心 (300, 478) / (724, 478)；瞳孔 r=58
- 脸轮廓一笔：`M 110 256 Q 154 278 154 332 L 154 688 Q 154 768 234 768
  L 790 768 Q 870 768 870 688 L 870 332 Q 870 278 914 256`
  （角尖 (110/914, 256)，嘴线 y=768，嘴角圆弧 r=80）
- 闪电：`452,768 → 496,706 → 528,830 → 572,768`，中段过 (512,768)，
  颜色在该点分界（左墨右虚，butt 端帽对接）
- 碳纹 pattern：45°，纹宽 36 / 间隙 32（周期 68）
- **间距铁则**：特征间净空 ≥ 一个笔画宽——眼环外缘到嘴线净空恰为
  72；嘴线在脸高 75%，眼心在 47%
- 构图水平/垂直双向居中；Android 自适应图标需按 66% 安全区缩排
  （出资产时处理，源文件不缩）
