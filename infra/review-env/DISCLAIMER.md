# 免责声明 / 使用边界（审核验证环境）

本环境（下文称「演示机」）只为 **Apple App Store 审核验证**而存在：让审核员能够完成
「配对 → 备份 → 浏览」这条链路，从而判断 App 的功能是否符合描述。

## 它是什么

- 一台临时的 Linux 服务器，跑 P-Pass 的 headless daemon，只存放**演示用**的图片
- 一个网页，负责生成配对二维码、显示待确认设备、允许/拒绝配对
- 账号密码只提供给审核方，并填写在 App Store Connect 的「审核信息」中

## 它不是什么

- **不是正式服务，也不是产品的一部分**：P-Pass 的设计是照片在用户自己的设备之间
  直连传输，不经过任何服务器；这台机器只是审核期间的一个临时落点
- **不是数据备份目的地**：随时可能被清空、被关停，不做任何可用性承诺
- **不接收真实数据**：请勿上传真实、私人或含敏感信息的照片

## 对审核员的要求

1. 只上传**示例图片**（系统自带示例图、截图，或任意不含个人信息的图片）完成验证即可
2. 上传的数据保存在这台临时服务器上，**审核结束后统一清空**
3. 请勿把访问地址、账号密码转发给他人
4. 若需要验证多设备/多次配对，可重复配对流程，无需保留上一轮数据

## 对运维（我们自己）的要求

1. 每轮审核结束后执行清空：停服务 → 删数据目录 → 重启（新身份、空库）
2. 提审期间除故障恢复外不更新 daemon、不改配置（保证审核跑的就是提交的那一版）
3. 演示机上的数据在审核窗口关闭后删除，不做留存、不做分析
4. 地址与凭据只写进 App Store Connect 审核信息，不进公开仓库、不发公开渠道
