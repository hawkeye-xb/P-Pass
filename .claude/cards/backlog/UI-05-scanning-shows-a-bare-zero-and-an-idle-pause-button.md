# UI-05 「正在找照片」后面跟一个裸的 0，而且这时候就有「暂停」按钮　级别 L3（backlog）

> 🔵 状态：backlog（验收人 2026-08-26 明确「暂时接受，开 backlog」）

## 问题

验收人反馈（2026-08-26 真机 0.4.0-test.8，回归步骤 #8）：

> 「小瑕疵，正在找照片后有个 0，并且这时候展示暂停，0 不知道何意味，这时候
> 应该处于计算状态吧，不用显示暂停吧，或者说这个是上传流程中的，可以考虑下
> 如何优化。」

两件事：

1. **裸的 0 没有意义。** 扫描阶段的进度是 `done/total`，扫描还没数完时两个
   都是 0，界面把它渲染成一个孤零零的「0」。用户不知道它指什么。
2. **扫描阶段就出现「暂停」按钮。** 这一阶段还没有一个字节在传，「暂停」
   暂停的是什么？`isBackupRunning` 把 Scanning/Hashing/Sending 三档一视同仁，
   英雄区按钮跟着一起出现。

## 值得想清楚的（不是直接照着改）

- 扫描阶段本身该不该有进度数字？扫描是一次 MediaStore 查询，快到不需要进度；
  真正慢的是 hashing。也许扫描阶段就只该说「正在找照片…」不带数字。
- 「暂停」在扫描/哈希阶段的语义是什么？管线是幂等的，中途停掉没有代价——
  所以**允许**暂停是对的，问题只是「按钮在没东西可停的那半秒里就冒出来」
  显得突兀。可能的出路：按钮延迟到 Sending 才出现；或者扫描/哈希阶段
  文案改成「取消」。
- 与 `UI-04`（提示呈现）和 `MOB-31`（进度总数）是同一片区域，一起改更省。
