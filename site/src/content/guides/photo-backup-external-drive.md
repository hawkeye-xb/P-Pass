手机里的照片和视频攒到几百 GB 之后，电脑自带硬盘往往不够放，很多人会选择把照片库放到外接移动硬盘上，或者过一段时间从默认目录整库搬到一块更大的硬盘。P-Pass 桌面端把「原文件」和「索引账本」分开存放，外接硬盘空闲时随时能安全弹出，没插盘时只暂停写入不删索引，换大盘也能直接整库搬迁且手机无需重新扫码或重传。

过去把照片库放在外接盘上常卡在三个问题：系统老提示磁盘正在使用弹不出来；忘插硬盘时软件误以为照片被删光而清空索引；真要换盘时怕手机得重新配对重传一遍。桌面端通过分离目录和库标记文件解决这三件事。

## 为什么把照片库放外接硬盘能随时安全弹出

以前很多备份工具弹不出移动硬盘，是因为索引数据库、传输记录和缩略图都写在照片库文件夹里，后台进程一直握着文件句柄不放。P-Pass 桌面端把这两类文件彻底拆开：

- **外接盘或照片库目录里**：只存放未压缩的原始照片和视频，加上一个极小的库标记目录 `.ppf/`，以及写入中必须在同一块盘上的临时中转文件。
- **电脑系统盘应用数据目录里**：SQLite 索引、缩略图和传输记录都放在电脑本地的应用数据目录（macOS 在 Application Support 下，Windows 服务在 ProgramData 下），按库 ID 各自建立子目录。

只要当前没有正在往外接盘写文件，后台服务不占用照片库目录里的任何句柄，在系统文件管理器或托盘里可以直接安全弹出。就算正好有一张照片写到一半你点了推出磁盘，后台会先停下当前这一张的写入并释放句柄放行弹出；等下次把硬盘插回电脑，手机会从断点把那一张补完，已经传完的不会重传，没传完的仍保留在手机上。

## 忘了插硬盘或改了目录名，会清空索引吗

不会。P-Pass 在照片库目录里放了一个库标记文件 `.ppf/library-id`，后台服务每次启动或准备写入前都会先核对标记在不在、库 ID 跟本机账本是否一致。

只要外接盘没插上，或者你在电脑上把照片库文件夹移走或改了名字，哪怕是在 P-Pass 运行途中直接拔盘，后台服务会立刻停掉对该目录的读写，进入「找不到照片库」的暂停状态：

1. **不猜、不新建、不删账**：不会把找不到盘当成照片全被删了去清索引，也不会在原路径偷偷新建空文件夹顶替。
2. **明确提示状态**：桌面首页切到「备份已暂停」提示并列出原先的路径，同时发出系统通知。
3. **自动恢复**：后台每 5 秒检查一次，把硬盘插回电脑或把文件夹放回原处后会自动恢复备份；你也可以在窗口里直接点「重新检查」立即恢复。这期间手机里的照片和配对关系都不受影响。

## 换一块更大的硬盘，怎么整库搬迁

电脑设置里的「更改照片库位置」会执行完整的整库搬迁。选定新目录（同一块盘或另一块外接硬盘都可以）并确认后，窗口会暂停备份并显示进度，按三步完成搬迁：

1. **搬迁前核对重名与可读性**：如果目标目录里本来就有你自己的其他文件，只要不与照片库顶层目录重名就会原封不动保留；有同名冲突则直接拒绝开始，不覆盖任何原有文件。跨盘搬迁前还会逐一检查源文件确保可读。
2. **用系统原生工具复制并逐项校验**：同盘内直接移动；跨盘调用系统复制工具（macOS 使用 `ditto`，Windows 使用 `robocopy`）把原照片、库标记和目录里你自己的其他文件一起拷过去，逐一核对文件大小、修改时间和索引里的每一张照片，全部对上后再切换配置并清理原位置。
3. **中途中断原库不动**：如果搬到一半你在文件管理器里改动了原库内容，搬迁会立刻取消并撤回新位置的临时文件，保留原库完整不动；如果遇到断电或程序退出，搬迁进度已保存在本机数据目录里，下次启动会接着处理。

因为 `.ppf/` 里的库 ID 跟着照片库一起搬走了，电脑设备身份没有变化，索引里记的也是相对于照片库根目录的路径，所以搬完之后手机无需重新扫码，已备份的照片也不会重传。

## 哪些目录会被直接拦下

无论是首次设置还是后续更换照片库位置，以下四类目录会直接拦下并说明原因：

- 电脑系统目录，以及桌面、文稿、下载、图片这些日常频繁变动的个人根目录本身（默认会在图片下建一个独立的 `P-Pass Library` 子目录，也可以自行新建专用子目录）。
- 第三方云盘同步目录，避免同步工具来回同步临时文件搅乱索引。
- 移动硬盘的根目录本身，需要在硬盘里建一个子文件夹作为照片库。
- 映射出来的网络盘、网络共享目录，或指向远程位置的文件夹链接。

## 使用边界提醒

把照片库放在外接硬盘上使用时，手机删掉照片依然不会删掉电脑和外接盘上的那份备份；备份需要电脑保持开机唤醒才能进行，断盘或休眠期间数据会留在手机上等待恢复后继续。
