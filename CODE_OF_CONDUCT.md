# Code of Conduct

[中文](CODE_OF_CONDUCT.zh.md)

P-Pass adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in all project spaces — issues, pull
requests, discussions and any other place where someone represents the
project.

In short: be respectful and considerate, accept constructive feedback, and
focus on what is best for the people using P-Pass. Harassment, insults,
personal or political attacks, and publishing other people's private
information without their permission are not acceptable.

## Reporting

If you experience or witness unacceptable behavior, report it privately
to the project maintainers at [ppass@hawkeye-xb.com](mailto:ppass@hawkeye-xb.com). All reports are
reviewed and handled in confidence.

The maintainers decide on consequences following the Enforcement
Guidelines of the Contributor Covenant 2.1: correction, warning,
temporary ban, or permanent ban, depending on the severity.
