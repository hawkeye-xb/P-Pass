# Windows 全量回归：人工操作版

这份 SOP 由**人**按顺序亲手操作。agent 只做两件事：往手机测试相册放照片，以及每步做完后取证（`tools/windows/manual-regression.sh snap <步骤号>`）。用例编号对应 [full-regression-sop.md](full-regression-sop.md) 的 R / W 系列，这样两份报告能直接对照。

## 每一步怎么交接

1. 你按「你做」操作。
2. 在对话里回：**「S几 好了」**，再加你看到的东西，尤其是：
   - 所有弹窗和提示的**原文**；
   - 等了多久；
   - 任何让你犹豫、看不懂、觉得不对的地方。
3. agent 取证：电脑和手机的进程、版本、注册表、配对状态、照片对账、日志、手机当前屏幕上的文字，存到 `%USERPROFILE%\ppcheck\manual\<步骤号>\`。

你描述的感受和 agent 取到的数据一起写进报告。手机全程用 USB 连着电脑，不要拔。

## 准备

- 安装包都在 `C:\Users\ethan\ppcheck\installers\`：
  - 电脑：`P-Pass_0.9.12-test.17_x64-setup.exe`（基线）、`P-Pass_0.10.0-test.3_x64-setup.exe`（候选）
  - 手机：`P-Pass_0.9.12_android.apk`（正式版）、`P-Pass_0.10.0-test.3_android.apk`（候选）
- 电脑和手机上的 P-Pass 都已卸载，旧数据已清空（数据在电脑回收站里）。

## 步骤

| 步骤 | 你做 | 回给我 | 对应用例 |
|---|---|---|---|
| **S0** | 手机打开「相册」，删掉 `PPassRegression` 和 `P-Pass` 两个相册（会进相册的回收站）。手机解锁、连着 USB | 删完了 | 清场 |
| **S1** | 告诉我开始。agent 用 adb 装正式版 APK。你在手机上打开 P-Pass，**按界面提示**授予权限（照片选「允许全部」）、通知；如果提示电池优化，照提示处理 | 每个权限弹窗的原文、你点了什么 | R0.1 + 开局人工批次 |
| **S2** | agent 先建好照片库目录（基线 test.17 自带 #871 的缺陷，不建会失败，候选版已修）。你在资源管理器里**双击** `P-Pass_0.9.12-test.17_x64-setup.exe` 安装 | SmartScreen 提示原文与你的处理；安装界面每一步；装完是否自动打开 | R0.2、R6.4 |
| **S3** | 打开 P-Pass。若弹「发现新版本 0.10.0-test.3」，点**取消**。走完向导三步 | 向导每一步的文字、哪里看不懂、最后停在哪个界面 | R0.3、W2 |
| **S4** | 告诉我开始。agent 往手机推 40 张测试照片 | — | 测试数据 |
| **S5** | 电脑「显示配对二维码」，手机「扫码连接」扫它，电脑上点「允许加入」。手机选相册**只勾** `PPassRegression`，开始备份，选「开启后台备份」 | 每一步的文字、二维码收起与确认的时机、备份用了多久 | R0.4、R0.5 |
| **S6** | 关掉电脑 P-Pass 窗口，从开始菜单再打开。弹「发现新版本」时点**确定** | 下载与安装的过程、是否有黑窗一闪、多久回到主界面、版本号 | R1.1（agent 先快照）、R1.2、R1.6、W1 |
| **S7** | 告诉我开始。agent 用 adb 覆盖安装候选 APK。你打开手机 P-Pass | 是否要重新配对、看到什么 | R1.3、R1.4 |
| **S8** | 告诉我开始。agent 推 8 张。你什么都不做，看手机和电脑 | 多久自动开始、多久完成 | R1.5 |
| **S9** | 告诉我开始。agent 推 300 张。agent 会请你点一次 UAC「是」（W4 采样） | 进度显示、手机发热和卡顿、通知栏 | R2.1、W4 |
| **S10** | 告诉我开始。agent 推 120 张。手机开始传之后，你**关 Wi-Fi**，30 秒后再打开 | 断网时手机说了什么、恢复后是否自己接着传 | R2.2 |
| **S11** | 告诉我开始。agent 推 120 张。手机开始传之后，你在最近任务里**划掉** P-Pass，5 分钟内不要打开；5 分钟后再打开 | 划掉后通知栏还有没有、重新打开看到什么 | R2.3 |
| **S12** | 手机照片墙随便点开 5 张，每张点「保存到相册」 | 保存提示原文 | R2.4 |
| **S13** | 在手机相册里删掉 `PPassRegression` 里的任意 5 张 | 删了哪几张（文件名或大概位置） | R2.5 |
| **S14** | 告诉我开始。agent 结束 daemon 进程。你看电脑界面 | 界面说了什么、多久恢复 | R3.2 |
| **S15** | 电脑托盘图标（隐藏图标区里名为 P-Pass 的那个）右键 →「停止后台服务」。等 2 分钟 | 托盘菜单与确认文字、停止后界面状态 | R3.3 |
| **S16** | 服务停着时，agent 推 5 张。你打开手机 P-Pass 看提示；然后「设置 → 存储电脑 → 断开与这台电脑的连接 → 确认断开」 | 手机上关于「连不上」的提示原文；断开前详情页显示什么 | R3.3、R4.1 |
| **S17** | 电脑「设置 → 启动后台服务」，等 2 分钟 | 电脑上该手机的状态变化 | R4.1、R4.2 |
| **S18** | 用二维码重新配对（同 S5，相册应该还记得） | 是否需要重新选相册、停机时的 5 张是否补上 | R4.3 |
| **S19** | 手机在前台放 1 分钟，然后**锁屏 3 分钟**，看电脑「家人与设备」里这台手机的在线状态 | 前台时和锁屏后各显示什么 | R6.2（熄屏，人工验收） |
| **S20** | 电脑「照片」页：数量和总览是否一致；点开一张大图；「在资源管理器中显示」 | 数量、是否选中了原文件 | R6.1 |
| **S21** | 手机系统语言切到英文，看首页、备份页、设置页，再切回中文 | 有没有截断、遮挡、没翻译的字 | R6.3 |
| **S22** | 托盘右键 →「导出诊断包」 | 导出提示、文件在哪 | R5.2（agent 检索隐私） |
| **S23** | P-Pass 开着时，**双击**候选安装包覆盖安装 | 是否提示文件被占用、装完的状态 | W3 |
| **S24** | Windows「设置 → 应用 → 已安装的应用 → P-Pass → 卸载」；再双击候选安装包重装并打开 | 卸载时的提示、重装后是否要重新配对 | W5 |
| **S25** | （可选）关掉手机「息屏显示」，锁屏放 1 小时以上，再打开 | 期间是否备份、恢复后是否补跑 | R3.4（熄屏，人工验收） |

## 收尾

- agent 做 R5.1 隐私检索，对全部照片做对账，按 [full-regression-sop.md](full-regression-sop.md) §7 写报告。报告里分开写「你的描述」和「取证数据」。
- 测试照片：电脑上的由 agent 移进回收站；手机上的由你在相册里删除（命令行只能永久删除，不做）。
