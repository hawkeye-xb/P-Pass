# UI-07 小图标上的闪电标消失了（疑似回归）

> ⬜ 状态：未开工
> 级别：L3 · 阻塞：无

## 问题

验收人 2026-08-27 反馈：「小 icon 上面的那个闪电标没了。」

2026-08-27 考据（负证据）：当前代码与 git 历史里搜 `⚡` / `FlashOn` /
`Bolt` / `lightning`，Android 与桌面端均无命中；ICON-02（功能小图标
改开源图标库）的提交也未涉及闪电徽章。即：**这个闪电标曾经在哪儿、
长什么样、何时消失的，目前无据可查**——它可能来自旧设计稿、旧版本
UI，或某个被重构掉的覆盖层。

## 期望行为

先考据后决定：弄清闪电标是什么（含义/位置/出现条件）、哪个版本还有；
若是有用信息的指示（如直连/快充/自动备份中），恢复之；若确认是有意
移除，把结论记录在本卡并关闭，不装死。

## 验收标准

- [ ] 考据结论写进本卡：闪电标的含义、原位置、最后出现的版本/提交，
  以及消失原因（哪次改动弄丢的，或从未实现过只是设计稿有）
- [ ] 若恢复：真机截图对照（有闪电标的状态 vs 无），含义与产品语义
  一致（不许再出现 UX-04 那种「状态机默认值说假话」的徽章）
- [ ] 若确认有意移除：卡面记录结论，QUEUE.md 同步

## 范围

- 只准动：考据后确定的图标/徽章所在端代码
- 不准动：图标资产管线（icon-assets）与本卡无关的部分
