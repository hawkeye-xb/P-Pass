# MOB-78 生产照片库混入 MOB-67 测试残留假文件（L1）

> ⬜ 状态：未开工——2026-09-14 真机验收 MOB-74 时顺带发现
> 级别：L1 · 阻塞：无

## 问题

个人开发机真实照片库 `~/Pictures/P-Pass 家庭照片库/originals/.../2026/09/
mob67-97d4df4bd962.jpg` 是一个 59 字节的假 JPEG（`file` 显示为畸形
JPEG 头，无实际图像数据），文件名带 `mob67-` 前缀——是此前 `MOB-67`
（失败通知开关）真机测试时人为造的坏文件，用来触发缩略图生成失败
路径，但测试完成后忘记从库目录清理，混进了真实照片库。

危害：
1. 照片墙里显示为一个无法解释来源的白框，容易和真正的视频/图片缩略图
   故障（如 `MOB-74`）混淆，干扰后续排障判断。
2. 生产照片库不应该residual 测试产物——这条数据不属于用户真实照片，
   却和真实资产一起入库、占用索引与缩略图存储。
