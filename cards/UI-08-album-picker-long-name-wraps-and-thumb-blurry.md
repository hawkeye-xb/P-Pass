## 问题

验收人 2026-08-27 反馈：「相册选择的时候，名称太长会换行，然后有点
模糊，小图。」

选相册页两个视觉问题：

1. 相册名过长时**换行**，把列表项高度撑乱（同行错位）；
2. 相册缩略小图**模糊**——疑似加载了过小尺寸的 thumbnail 再放大显示，
   或请求尺寸与显示尺寸不匹配。

## 期望行为

- 相册名一行显示，超出省略号收尾（或与设计稿一致的处理）；
- 缩略图按显示尺寸请求合适分辨率，清晰不虚。

## 代码完成记录（2026-09-08）

- 根因：`decodeBucketCover` 原先无条件用 `loadThumbnail(Size(200, 200))`，而
  封面卡片按网格宽度和 `aspectRatio(1.6f)` 显示；高密度/更大显示尺寸会把低分辨率
  位图放大。长名称的 `Text` 使用 `weight(fill = false)` 且没有单行/溢出约束，Row
  会让文本参与不稳定的宽度测量并换行。
- 修复：封面 Box 通过 `onSizeChanged` 取得实际像素 `IntSize`，以该宽高调用
  `loadThumbnail`，并把尺寸写入内存缓存 key，避免不同显示尺寸复用低分辨率位图；
  相册勾选集合、桶 id、计数表达式未改。名称改为 `weight(1f)` + `maxLines = 1`
  + `TextOverflow.Ellipsis`。
- 覆盖：新增 `UI08BucketScreenTest` 两条源码守卫；先跑红（2 failures），再跑绿。
  Android JVM 全量 `testDebugUnitTest --rerun-tasks`：**313 tests / 0 failures /
