## 准备工作（一次性，5 分钟）

### 1. 下载 Android Probe App

在 Android 手机上打开：
**https://github.com/hawkeye-xb/P-Pass-buisness/releases/tag/s03-android-probe**

下载 `app-debug.apk` → 安装（允许"未知来源"）。

### 2. 电脑装 iroh-probe CLI

打开终端，跑：
```bash
cd ~/workspace/P-Pass/spikes/iroh-probe
cargo run --release -- listen
```

保持这个终端开着，记下屏幕上的 **NodeId**（一串字母数字）。

## 测试操作（每场景重复，5~8 分钟一个场景）

### 每场景标准流程

1. **电脑**：确保 iroh-probe CLI 还在 listen（如果关了，重新跑 `cargo run --release -- listen`）
2. **手机**：打开 Probe App → 粘贴电脑 NodeId → 点 **「Dial + Send 100MB x20」**
3. **等**：App 会连 20 次，每次显示结果（直连 or 中继、延迟、速度）
4. **记录**：跑完后 App 里点 **Share Log** → 发给自己（微信文件传输/邮件）→ 填下表

## 8 个场景

| # | 场景 | 手机连什么网 | 电脑连什么网 | 怎么搞 |
|---|------|------------|------------|--------|
| 1 | **同 WiFi** | 家里 WiFi | 家里 WiFi | 最简单——手机和电脑都在家连同一个 WiFi |
| 2 | **家宽 → 4G** | 关 WiFi，用 4G/5G | 家里 WiFi | 手机切蜂窝，电脑在家不动 |
| 3 | **4G → 家宽** | 家里 WiFi | 手机开热点给电脑连 | 手机开热点→电脑连手机热点→手机用 WiFi 连家里网（或者反过来：电脑开热点手机连也行，反正一边蜂窝一边宽带的交叉） |
| 4 | **双运营商 4G** | 4G SIM A | 另一张卡开热点 | 如果你有两张不同运营商的 SIM（比如移动+联通），一张插手机用 4G，另一张开热点给电脑连。**仅当有两张不同运营商 SIM 时做** |
| 5 | **同运营商 4G** | 4G SIM A | 同卡开热点 | 同一张 SIM，手机连 4G，电脑连手机热点。**仅当有多张同运营商 SIM 时做，否则跳过合并到#4** |
| 6 | **公共 WiFi** | 咖啡店/酒店/商场 WiFi | 家里 WiFi | 拿手机出去找个公共 WiFi（咖啡店最好，坐下来喝杯咖啡），电脑在家不动。**出门的这一天顺便做** |
| 7 | **公司/企业网** | 公司 WiFi | 家里 WiFi | 上班时在公司用手机连公司 WiFi 跑，电脑在家不动。**工作日做** |
| 8 | **IPv6-only** | 5G IPv6 | WiFi IPv6 | **可选。** 需要确认两边都有 IPv6 地址。不知道怎么确认就跳过 |

## FAQ

**Q: 不会跑 cargo 命令？**
A: 打开终端，复制粘贴命令后按回车。电脑上需要已装 Rust（你装过 Xisper 构建环境就有）。

**Q: 跑失败了/打不开/不工作？**
A: 截图/描述现象扔到 Discord，我来排查。

**Q: 8 个场景要一次性全跑完？**
A: 不用。场景 1~3 一天（30 分钟），4~5 有对应 SIM 就做，6~7 出门/上班顺便，8 可跳过。跑几个填几个。全完成了叫我。
