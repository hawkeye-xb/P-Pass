# DEV-01b 重装识别入口先隐藏　级别 L0（用户拍板 2026-08-12）

用户裁决：重装识别/「替换旧设备」入口**先隐藏**——现阶段统一走
「重新扫码 = 全新授权」，不给用户多一个要理解的概念。

## 修法

- 桌面允许对话框的「替换旧的 X」选项加开关默认关（编译期常量或简单
  flag，别过度设计）；关闭时对话框与 DEV-01 之前完全一致。
- **底层不拆**：pair.request 的 device_hint 照发照存（数据继续积累，
  未来打开开关即用）；Android 设置页「重装识别」开关行一并隐藏。

## 可执行验收

1. 同 hint 重配对 → 允许对话框**不出现**替换选项，走新设备路径（集成
   测试断言 UI 数据里无 merge 字段/桌面无该分支渲染）。
2. daemon 侧 hint 仍入库（存储断言）。
3. 反证：打开 flag → 替换选项回来（贴对照后还原，证明只是藏不是删）。
