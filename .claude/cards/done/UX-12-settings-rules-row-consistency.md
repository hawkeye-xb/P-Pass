# UX-12 设置页规则卡行高/间距不统一　级别 L0　【用户走查反馈 2026-08-12】

## 背景

用户看完 UX-09/UX-10 后走查设置页，反馈两点：①卡片圆角较大（20dp），
但列内容第一行、最后一行紧贴上下边缘，视觉局促；②带 `Switch` 开关的
行明显比纯文字行更高，行与行高度参差。

## 根因

- 带 Switch 的行（`RuleSwitchRow`）用 `padding(16.dp, 8.dp)`；纯文字行
  （通知/版本/备份范围/立即备份）用 `padding(16.dp, 14.dp)`。两种 padding
  本意是各自凑出差不多的行高，但 `Switch` 组件自带的最小触控尺寸比单行
  文字的固有高度更大，即使 padding 更小，最终行高仍然更高——两条不同
  的 padding 规则反而放大了不一致，不是缩小。
- 整列 `Column` 没有独立的上下 padding，行内容直接贴着 `Surface` 的
  20dp 圆角内壁。

## 修法

1. 定义统一的 `RuleRowMinHeight = 56.dp`，所有单行（Switch 行 + 4 个
   纯文字行）改用 `heightIn(min = RuleRowMinHeight).padding(horizontal
   = 16.dp)`——不再靠垂直 padding 的差异去凑行高，靠同一条最小高度
   兜底、内容垂直居中。带 hint 的两行开关（"自动备份"）内容本身更高，
   自然超过这条下限，是合理例外。
2. 规则卡的行 `Column` 整体加 `padding(vertical = 8.dp)`，给第一行、
   最后一行让出和圆角弧线的呼吸空间。

## 可执行验收

1. android 全量单测绿（纯视觉调整，无可自动化断言的新行为）。
2. 真机（挂用户）：设置页规则卡里开关行和文字行目测同高；顶部/底部
   行不再贴着圆角。
