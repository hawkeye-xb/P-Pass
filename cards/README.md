# 任务卡

一卡一文件，格式按 `TEMPLATE.md`（🟥 挂号 → ⬜ 可接 → 🟡 待验收 → ✅ 归档进 `done/`）。

- 卡是唯一事实源：干什么、怎么算完、不许碰什么，都在卡里。
- agent 工作规范在仓库根 `AGENTS.md`——先读它，别的不用读。
- 待办与优先级看 `docs/QUEUE.md`（验收人仪表盘，agent 不读）。
- 本机环境状态（路径/设备/daemon 状态）不进卡，统一放 `local-state.md`（不进 git）。
- 卡的位置不是事实，代码与横幅才是：回答"做了没"必须先核实代码，不看目录。
