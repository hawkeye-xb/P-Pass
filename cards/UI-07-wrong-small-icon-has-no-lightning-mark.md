# UI-07 小 icon 用错版本——用了没有闪电标识的那个

> ⬜ 状态：未开工
> 级别：L3 · 阻塞：等验收人给修改指示（用哪个带闪电标的 icon）

## 问题

验收人 2026-08-27 反馈：「小 icon 上面的那个闪电标没了。」

同日定性（验收人原话）：**不是徽章丢了，是小的 icon 使用错了——用了
没有闪电标识的 icon**。即图标资产里存在带闪电标和不带闪电标的版本，
当前界面引用的是不带闪电标的那个。修法验收人会直接告知。

（2026-08-27 曾按「回归」方向考据：全历史搜 ⚡/FlashOn/Bolt 零命中——
现在有了定性，这个负证据不用追了，闪电标是图标资产本身的视觉元素，
不是代码里的独立徽章。）

## 期望行为

小 icon 换回带闪电标识的版本（具体引用哪个资产、换哪几处，按验收人
给的指示执行）。

## 验收标准

- [ ] 按验收人指示替换 icon 引用，真机/截图对照：闪电标出现
- [ ] 确认所有用到这个小 icon 的位置都换（不漏同名资产的其它引用点）

## 范围

- 只准动：验收人指示的 icon 引用处
- 不准动：图标资产管线（icon-assets）本身、其它图标

## 阻塞与依赖

等验收人给「用哪个带闪电标的 icon、换哪里」的指示，拿到即做。
