## 核心裁决摘要

- **桌面端**：单页长滚动 → 侧边栏四页（总览 / 家人与设备 / 活动记录 / 设置，照片库并入设置）；
  顶部徽章只说服务状态，连接状态归属每台设备行
- **手机端**：只有两个 tab——照片页 = 统一时间线 + 轻过滤器；备份页 = 恒真三元组 +
  可暂停 + 失败才说话
- 危险操作只在电脑上
- 第 2 轮新增：桌面首启向导 / 手机 Onboarding / 大图页
